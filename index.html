US Patent 11,983,236 · Granted May 2024

PATENT 01 OF 10

Failure Detection
& Recovery

The immune system. It doesn't just run — it heals.

When you're automating tasks across dozens of live websites simultaneously, things break. Websites change layouts. Sessions time out. Data feeds return unexpected errors. Without recovery logic, the whole system fails silently. This patent covers the mechanism that detects failures mid-execution — wherever they occur in the automation pipeline — and automatically triggers a defined recovery path to resume operations without human intervention. It's not error handling in the traditional sense. It's a live immune system that keeps the automation running even when the outside world doesn't cooperate.

US Patent 11,860,967 · Granted January 2024

PATENT 02 OF 10

Descriptor
Normalization Engine

Universal translation for a fractured product universe.

Healthcare product data is a disaster. A single syringe might be called "5mL Luer Slip Syringe" on one platform, "Syringe 5cc LS" on another, and "5 ml sterile disposable syringe" on a third. These aren't just different labels — they're barriers to automated procurement, price comparison, and inventory matching. This patent covers the system for ingesting descriptors from multiple heterogeneous sources, running similarity scoring to detect what's actually the same product, and normalizing them into a unified model. This is how MetaCommerceRx compares apples to apples across 200+ supplier catalogs — automatically, at scale, without human SKU-matching.

Decomposition

The conductor of the AI orchestra.

A complex healthcare supply chain task — verify this drug's DSCSA compliance, find three competing prices, route the order to the right distributor, and log it in the EHR — cannot be executed with a single command on a single platform. This patent covers the architecture for taking that complex task, breaking it into discrete sub-tasks each with a defined goal, and routing them for parallel execution across multiple platforms simultaneously. US Patent 12,468,774 · Granted November 2025

PATENT 04 OF 10

Intelligent Data
Reacquisition

The system that knows when it doesn't know enough.

Healthcare data has a half-life. Drug prices change daily. Formularies update without notice. Manufacturers get acquired. A procurement AI that relies on stale data isn't just inefficient — it's dangerous. This patent covers the logic for evaluating previously acquired data, determining whether it has become unreliable or outdated, and triggering automatic reacquisition via the established description model. It's the engine that keeps TradeSpy.ai's intelligence current — autonomously, continuously, without a human scheduling a refresh. The system doesn't wait to be told the data is old. It figures it out.

US Patent 11,640,440 · Granted May 2023

PATENT 05 OF 10

Website Structure
Identification

The AI's ability to read any website like a blueprint.

Before any automation can happen, the system must understand the structure of the website it's working with. This patent covers the identification of website structure portions — the layout, fields, buttons, navigation elements, data containers — and their association with descriptors that define a data description model. It's the capability that lets iRemedy's AI "see" a website it has never encountered before and immediately understand how to navigate it, extract data from it, and interact with it — without custom coding, without manual mapping, without APIs. Automation Process
Execution

Healthcare data has a half-life. Drug prices change daily. Formularies update without notice. Manufacturers get acquired. A procurement AI that relies on stale data isn't just inefficient — it's dangerous. This patent covers the logic for evaluating previously acquired data, determining whether it has become unreliable or outdated, and triggering automatic reacquisition via the established description model. It's the engine that keeps TradeSpy.ai's intelligence current — autonomously, continuously, without a human scheduling a refresh. The system doesn't wait to be told the data is old. It figures it out.

Website Structure
